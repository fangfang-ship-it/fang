# 天空横向双拼与底色填充

新增 ComfyUI 节点：

`Sky Repeat Top + Bottom Color / 天空横向双拼与底色填充`

输入严格 2:1 的天空图，将整张输入图缩小为半宽、半高，横向重复两份铺满画面上半部；画面下半部读取输入图底边的平均色并进行纯色填充。输出尺寸与输入完全一致。

## 2048×1024 示例

- 输入：2048×1024。
- 每份缩小图：1024×512。
- 上半幅：两份 1024×512 图左右相连。
- 下半幅：2048×512 纯色区域。
- 输出：2048×1024。

## 参数

- `resize_method`：默认 `bicubic`，也可选择 `bilinear`、`area`、`nearest-exact`。
- `sample_rows`：默认 `1`，读取原图最底边一行的所有像素并求平均色。若底边存在压缩噪点，可设为 `2`—`4`。

## Byteartist

插件地址：`https://github.com/fangfang-ship-it/fang.git`

分支：`main`

更新或重新下载插件并重新加载运行环境后，搜索 `Sky Repeat Top` 或 `天空横向双拼与底色填充`。

连接：`加载图像 → 天空横向双拼与底色填充 → 保存图像`

节点要求输入宽度严格等于高度的两倍，并要求高度为偶数。节点不会修改输出分辨率，不进行 AI 扩图，不修复原图自身的左右接缝，也不会自动生成真正的 HDR 数据。
