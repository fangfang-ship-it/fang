# 最低云端识别数值解析与垂直对齐

该流程把语义判断和确定性像素处理分开：识图模型负责判断最低云端位置，自定义节点负责安全解析数值、移动图片和纯色补空。

## 推荐链路

`加载图像 → 识图模型`  
`识图模型文字输出 → Sky Parse Cloud Bottom %`  
`加载图像 + 解析出的 FLOAT → Sky Align Cloud Bottom → 保存图像`

## 识图模型提示词（局部结构判定版）

你的任务是定位输入天空图中“所有云相关结构的最低有效像素位置”，包括普通云、薄云、云丝以及附着在云形上的局部霞光。

高度从画面顶边0%向下计算，画面底边为100%。必须扫描画面完整宽度，并从画面底部向上寻找第一个仍属于有效云相关结构的位置。最终结果取所有有效结构中Y值最大的点，也就是画面里最低的云端。不要输出主体云团的平均云底，也不要只观察最大、最明显的云。

判断的核心不是亮度、颜色或是否越过地平线，而是该区域是否仍具有“局部、非均匀、可辨识的形态结构”。

以下内容必须计入：

- 具有明确方向、边缘、宽窄变化、分叉、羽状纹理、丝状纹理或密度变化的云丝、薄云和碎云。
- 与云丝或云体相连，并沿局部形态发生颜色、亮度或透明度变化的霞光。
- 彩虹色、粉色、金色、蓝绿色等非白色云丝，只要仍有局部轮廓或纹理，也必须计入。
- 低对比、半透明、接近背景色，但仍能看出走向、边缘或内部变化的云尾。
- 位于地平线、参考线或50%中线以下的云丝和局部霞光。不得因为它们越过某条水平线而忽略。
- 主体云团下方零散、细小或断续的远云。必须比较整张图所有位置，取其中最低者。

以下内容不得计入：

- 横跨大部分画面、整体连续且平滑，没有独立轮廓、方向或纹理的全局霞光。
- 太阳或其他光源周围均匀扩散的光晕、过曝区和镜头光斑。
- 平直或近似平直的地平线亮带，以及沿整条地平线均匀铺开的颜色。
- 只发生缓慢色彩变化、没有局部形态结构的大气渐变。
- 大面积均匀雾化、整体薄雾、无结构的大气散射。
- 纯色填充区、平滑延伸区、水面、地面、倒影和无关景物。
- JPEG压缩、噪点、单个亮点或孤立的1—2像素伪影；只有形成连续且可辨识的线状或块状结构时才计入。

局部霞光与整体霞光的区分规则：

- 如果光色附着在一条具体云丝、云边或云块上，随该形态弯曲、分叉、变宽、变窄或改变强弱，它属于云相关结构，必须计入。
- 如果光色只是大范围均匀铺开，边缘模糊、变化平缓、没有独立形状，即使颜色很亮，也属于整体环境光，不计入。
- 云形与霞光混合时，应沿着仍存在局部方向、轮廓或纹理的区域继续向下追踪，直到这些结构完全消失。最后一处仍有结构的位置才是最低云端。

在内部完成以下检查，但不要输出检查过程：

1. 先识别所有具有局部结构的云体、云丝和附着霞光。
2. 单独复查画面高度40%—60%的区域以及地平线以下区域，避免遗漏低位细丝。
3. 排除平滑的全局霞光、光晕、亮带、渐变、雾化和填充区。
4. 在所有保留区域中选择Y值最大的最低点。
5. 如果边界介于“有结构”和“完全平滑”之间，取最后仍能辨认出方向、边缘或纹理的位置，倾向选择稍大的百分比，避免把云底判断得过高。

只输出以下JSON，不要输出分析、解释、置信度、分辨率、像素坐标、单位、代码块或其他数字：

`{"cloud_bottom_percent":46.5}`

将示例数值替换为实际结果，保留一位小数。

## 节点一：Sky Parse Cloud Bottom %

- 优先读取 `cloud_bottom_percent` 字段。
- 也接受唯一一个带 `%` 的数值或只有一个数字的纯文本。
- 文本含多个不明确数字时停止报错，避免误把分辨率、置信度等数值当成云底。
- 输出 `cloud_bottom_percent`（FLOAT）和解析说明。

## 节点二：Sky Align Cloud Bottom

- `cloud_bottom_percent`：连接解析节点，或手动输入。
- `target_percent`：默认 `49.7`，即当前参考线位置。
- `max_shift_percent`：默认 `15`。所需位移超过限制时停止，防止模型误识别导致整张图被大幅移动。
- `fill_sample_rows`：默认 `1`，用于计算露空区域的纯色。

图片仅做整数像素垂直平移，不缩放。向下移动时顶部空区使用原图顶边平均色；向上移动时底部空区使用原图底边平均色。输出移动后的图片、移动像素、识别位置、目标位置和处理说明。

例如：输入高度1024，识图结果46.5%，目标49.7%，节点向下移动约33像素，并在顶部补纯色。
