# 1:1 转固定 2:1 节点

节点名称：

`Sky Square to 2:1 4096x2048 / 1:1转2:1固定尺寸`

## 功能

- 输入必须为严格 1:1 正方形图片。
- 输出固定为 **宽 4096 × 高 2048**，比例严格 2:1。
- 完整保留输入画面，不裁切、不复制、不补边；通过横向重采样转换比例。
- 支持批量图片和 ComfyUI IMAGE 浮点张量。

## 参数

- `resize_method`：默认 `bicubic`，也可选 `bilinear`、`area`、`nearest-exact`。

## 使用

更新仓库 `main` 分支并重新加载 ByteArtist 运行环境后，在画布中搜索：

- `Sky Square to 2:1`
- `1:1转2:1固定尺寸`

连接方式：

`加载图片 → 1:1转2:1固定尺寸 → 保存图片`

节点额外输出 `width=4096`、`height=2048` 和处理信息，便于检查链路结果。
