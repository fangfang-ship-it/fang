# 1:1 转 2:1 左右补白节点

在 `Sky Tools` 分类下搜索 **1:1转2:1左右补白** 或 **Sky Square to 2:1 White Pad**。

- 输入 **2048 × 2048**，输出 **4096 × 2048**（宽 × 高）。
- 原图居中逐像素复制，左右各补 **1024 像素纯白**。节点直接输出 IMAGE 张量，保留输入的批次、通道和数值精度。
- 更新仓库 `main` 后，重启 ComfyUI 或重新加载 ByteArtist 运行环境。

工作流 **加载图片 → 1:1转2:1左右补白 → 保存图片**。导出时使用 PNG 可避免有损编码。

## 1:1 全画面缩放节点

节点名称：

`Sky Square to 2:1 4096x2048 / 1:1转2:1固定尺寸`

### 功能

- 输入必须为严格 1:1 正方形图片。
- 输出固定为 **宽 4096 × 高 2048**，比例严格 2:1。
- 完整保留输入画面，不裁切、不复制、不补边；通过横向重采样转换比例。
- 支持批量图片和 ComfyUI IMAGE 浮点张量。

### 参数

- `resize_method`：默认 `bicubic`，也可选 `bilinear`、`area`、`nearest-exact`。

### 使用

更新仓库 `main` 分支并重新加载 ByteArtist 运行环境后，在画布中搜索：

- `Sky Square to 2:1`
- `1:1转2:1固定尺寸`

连接方式：

`加载图片 → 1:1转2:1固定尺寸 → 保存图片`

节点额外输出 `width=4096`、`height=2048` 和处理信息，便于检查链路结果。
