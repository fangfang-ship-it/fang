# 天空底色扩充至正方形

新增 ComfyUI 节点：

`Sky Extend Bottom Color Square / 天空底色扩充至正方形`

输入 2048×1024 的 2:1 图片，保持原图像素与尺寸不变，放在新画布上半幅；保留原图最底一行中每个横向位置自己的颜色，把整行逐行向下延伸，填满新增的下半幅，输出 2048×2048。左右色差和横向渐变不会再被压成单一平均色。新增区域单独进行横向高斯模糊，以减弱逐列延伸形成的竖向线条；原始上半幅不参与模糊。

## 参数

- `blur_radius`：默认 `6.0`，只控制新增下半幅的横向模糊；设为 `0` 可关闭模糊。
- `blend_height`：默认 `64` 像素。连接处第一行保持与原图底边完全一致，随后在该高度内逐渐过渡到完整模糊，避免产生新的横向接缝。

## Byteartist

插件地址：`https://github.com/fangfang-ship-it/fang.git`

分支：`main`

更新或重新下载插件并重新加载运行环境后，搜索 `Sky Extend Bottom Color Square` 或 `天空底色扩充至正方形`。

连接：`加载图像 → 天空底色扩充至正方形 → 保存图像`

节点兼容其他严格 2:1 尺寸，例如 4096×2048 → 4096×4096。节点不缩放、不裁切、不横向复制原图，也不进行 AI 扩图。模糊采用左右环绕方式，避免破坏天空盒左右边界的连续性。
